# Tugas-Kelompok-RPL

Aplikasi Pemesanan Kasur Berbasis Web pada Toko Kasur Taciex Foam.

Aplikasi ini membantu toko mengelola pemesanan kasur, mulai dari pilihan tipe kasur, pencatatan pesanan, konfirmasi, sampai pembayaran dan laporan.

  Fitur
- Login dan hak akses
- Data tipe kasur
- Pemesanan kasur
- Konfirmasi pemesanan
- Metode pembayaran
- Riwayat pesanan dan laporan

 Isi Repositori
Dokumen SRS dan diagram (Use Case, Activity, Sequence, State Machine) untuk perancangan aplikasi.
